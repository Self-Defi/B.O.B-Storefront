# Lesson 03 — Your First Owned Website
A static site with no dependencies or required subscriptions.

1. Download `index.html` and `styles.css` into the same folder.
2. Open `index.html` in a browser. You should see a homepage, two sample services and a contact section.
3. Edit the business name, service descriptions, location and contact email in `index.html`. Edit colors in `styles.css`.
4. Keep files in a repository under **your own** GitHub account.
5. Deploy through GitHub Pages or Cloudflare Pages. Exact account UI can vary; use the platform's current official documentation.
6. Confirm HTTPS, mobile readability, working navigation, and no placeholder email before sharing.
7. Avoid collecting personal information until you've implemented appropriate privacy, access control and secure backend processing.

This starter is different from the production AZHomeInstalls site: its CRM, form handling and Cloudflare D1 features are deliberately omitted. Publishing a static starter does **not** recreate those systems.

B.O.B. criteria: understandable process, documented costs, user-owned source and hosting account, no mandatory SaaS subscription.
