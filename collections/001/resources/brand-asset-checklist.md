# B.O.B. — Brand Asset Export / Acceptance Checklist

### Required
- [ ] A name selected after an availability check (name, domain, relevant registrations/trademark checks)
- [ ] One-sentence customer promise and clearly defined service scope
- [ ] Logo with editable source in an account/repository owned by the learner
- [ ] Dark-on-light and light-on-dark versions
- [ ] Square profile-icon version, legible at small size
- [ ] Colors with HEX values and documented usages
- [ ] Typography documented, including licenses and fallback fonts
- [ ] One-page brand guide completed
- [ ] Images tagged authentic client / owner project / concept as applicable
- [ ] Costs and recurring charges recorded (even when $0)
- [ ] Public photos/screenshots inspected for customer personal information
- [ ] A second person can locate and export the brand files without the original designer's login

### File naming convention
`brand-primary.svg`
`brand-primary-dark.svg`
`brand-avatar.png`
`brand-monochrome.svg`
`brand-standards.md`
`brand-budget.csv`

### Demonstration acceptance
1. Copy the completed brief into a new folder.
2. Create a brand mark from basic shapes/type in a vector editor or another tool with export permissions.
3. Export transparent PNG and SVG (if supported by the tool).
4. Display the mark at 160px, 320px, and full width.
5. Make one revision to the original file and re-export it.
6. Have a different person open the files, locate the rights notes, and edit a color without buying a subscription.
7. Mark YES only if all three B.O.B. tests pass. Otherwise document what remains.
