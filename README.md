# B.O.B. — Building on a Budget

**Build It. Own It. Control It.**

Independent source repository for the B.O.B. educational storefront. We teach practical builds based on real working systems, prioritizing ownership of source code, infrastructure, credentials and data.

## Current status

- Version: v0.2 initial standalone migration
- Functional: static mobile-responsive homepage, project cards, method, AZHomeInstalls case-study summary
- In development: standalone case-study page, downloadable tutorials, checkout, verified financial documentation, final production brand asset
- **No payments or lead submissions are enabled.**

## Local preview

Open `index.html` in any modern browser. No dependencies or build commands required.

## Deployment

This is a static site compatible with GitHub Pages or Cloudflare Pages. In GitHub repository **Settings → Pages**, choose **Deploy from a branch → main → /(root)**. For a project repository the eventual URL will typically be `https://self-defi.github.io/B.O.B-Storefront/` once Pages has deployed. Existing preview currently lives at `https://self-defi.github.io/bob/` from the separate site repository.

## Provenance

The AZHomeInstalls project is a real operated business and serves as B.O.B.'s first case study. Do not publish customer data, credentials, or unsupported financial claims.

## Brand and dependencies

Current hero illustration and glass UI are HTML/CSS; final B.O.B. logo artwork has not yet been integrated. Before publishing third-party source or logos, review applicable licenses/trademark restrictions.
